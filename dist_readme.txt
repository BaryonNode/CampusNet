========================================
 CampusNet · 校园网自动认证  使用说明
========================================

【这是什么】
不用打开浏览器、不用点任何按钮，自动帮你完成校园网认证。


【怎么用】
1. 把整个 CampusNet 文件夹解压到任意位置（比如桌面）。
   ※ 不要只复制 CampusNet.exe，它旁边的文件是必需的。

2. 先手动连上校园网（就是平时会弹"需要操作/打开浏览器连接"的那个网络）。
   连上后先别点浏览器，让它弹着就行。

3. 双击 CampusNet.exe
   - 第一次会弹出配置窗口
   - 填：账号、密码，选一下校园网
   - 点【自动探测并保存】
   - 看「服务/运营商」这一栏：默认是【移动互联网服务】。
     如果认证失败提示"服务不能为空"或"服务不正确"，
     就在下拉框里换成别的（联通互联网服务 / 电信互联网服务 / 校园网）。
   - 点【立即测试连接】

4. 以后每次双击 CampusNet.exe 就会自动认证，不会再弹窗口。

5. 想让它在联网时自动认证（推荐）：
   在配置窗口里点【开机自动认证】。
   注册后程序平时完全不运行，不占内存；网络一连上就自动认证。


【如果 Windows 提示"已保护你的电脑"】
这是没有数字签名的正常提示，不是病毒。
点【更多信息】→【仍要运行】即可。


【没成功怎么办】
1. 看同目录下的 logs\campusnet.log，里面有每一步的详细记录
   （账号密码会被自动打码，不会泄露）
2. 打开 CampusNet-cli.exe，输入：
       --check          看看当前到底通没通
       --wlan-scan      看看校园网名字对不对
       --detect         看看能不能自动识别认证服务器
       --dry-run -v     演练一遍，不真正提交
3. 把 logs\campusnet.log 发给开发者


【常见情况】
* 提示"服务不能为空"或"服务不正确"：说明你学校的网关同时提供校园网和
  多家运营商，必须指定正确的那一个。在配置窗口的「服务/运营商」下拉框里
  换一个（默认是移动互联网服务），保存后再试。
* 提示"需要图形验证码"：通常是密码输错多次导致的，
  先在浏览器里正常登录一次就能清除。
* 认证成功但浏览器打不开网页：多半是电脑上还开着代理软件，
  关掉即可。
* 提示"当前已可正常上网，无需认证"：说明网络已经通了
  （校园网常会按设备记住一段时间），属于正常现象。
